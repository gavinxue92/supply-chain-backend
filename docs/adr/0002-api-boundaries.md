# ADR-0002：版本化 REST API 与访问边界

- **状态**：已接受
- **日期**：2026-11-16

## 背景

同一业务后端供微信小程序和运营管理后台调用。客户浏览无需登录；后台业务写入和管理功能需要认证与权限控制。两类调用方需要可独立演进的接口边界。

## 决策

- 提供版本化 REST/JSON API，首期路径前缀为 `/api/v1`。
- 明确区分公开浏览 API 与受管理会话保护的后台 API。
- 公开 API 只暴露已上架且所属分类可见的产品信息，不要求客户注册或登录。
- 管理 API 按管理员和运营编辑角色授权。
- 提供 OpenAPI 3 契约；Swagger UI 仅在非生产环境开放。

## 后果

- 接口契约可供两个前端独立集成，并可通过版本前缀演进。
- 公开数据与后台管理操作不会共享隐式的登录要求。
- API 的具体端点、分页细节和错误响应格式由实现规格进一步定义，不在本决策中假定。
