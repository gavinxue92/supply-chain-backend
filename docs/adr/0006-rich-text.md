# ADR-0006：产品详情内容安全

- **状态**：已接受
- **日期**：2026-11-16

## 背景

运营需要以图文混排介绍食材，内容由后台编辑并在微信小程序展示。直接接收和展示任意 HTML 会带来不必要的内容安全与兼容性风险。

## 决策

- 产品详情采用受限 HTML 表达。
- 服务端对保存内容进行白名单清洗，只保留允许的基础格式、段落、标题、列表、加粗和图片等内容。
- 拒绝脚本、任意样式、嵌入内容和非本系统登记的外部图片。
- 详情图片只允许引用本系统媒体 API 路径，并且必须是当前运营操作者有权使用的已确认媒体资源。
- 小程序按兼容的富文本节点展示清洗后的内容。

## 后果

- 服务端清洗是信任边界，前端编辑器不能替代服务端校验。
- 清洗策略和前端允许的富文本元素必须保持兼容并有测试覆盖。
- 具体清洗库尚未选定；不得把未经清洗的内容直接持久化为可执行 HTML 并呈现。
