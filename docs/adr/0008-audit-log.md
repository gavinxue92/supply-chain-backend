# ADR-0008：关键业务操作审计

- **状态**：已接受（覆盖范围扩展见 ADR-0010、ADR-0011、ADR-0012）
- **日期**：2026-11-16
- **更新**：新增账号昵称/硬删除、客服实体与挂载、媒体删除等审计动作；不含认证秘密和一年保留期继续有效。

## 背景

多个运营账号会管理产品、分类和客服配置，需要能够追溯关键变更；审计数据不能泄露认证秘密。

## 决策

- 记录关键业务操作的操作者、时间、目标对象及变更摘要。
- 覆盖产品、分类、产品客服、全局客服和后台账号等关键新增、修改、上下架、归档/恢复及管理操作。
- 审计记录保留一年。
- 不记录密码、会话令牌或其他认证秘密。

## 后果

- 关键变更应由后端统一产生审计记录，不能依赖前端上报作为唯一来源。
- 审计记录与业务变更应保持一致，避免操作成功但记录缺失，或失败操作被记录为成功。
- 本决策不要求完整操作回放或独立备份策略。
