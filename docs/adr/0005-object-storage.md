# ADR-0005：对象存储与图片上传

- **状态**：已接受（图片删除与清理部分被 ADR-0012 取代）
- **日期**：2026-11-16
- **更新**：下文“图片删除、孤儿资源清理……尚未指定，不应擅自作为首期验收要求”已由 ADR-0012 明确替代。

## 背景

产品主图、轮播图、详情图和客服二维码由运营维护。图片需要可由小程序公开展示，同时后台上传必须受身份权限控制。生产对象存储厂商尚未确定。

## 决策

- 通过 S3 兼容接口访问对象存储；本地 Docker Compose 使用 MinIO，生产云厂商后续选定。
- 管理端先向业务服务申请短时上传凭证，再直传对象存储；业务服务确认上传并登记资源。
- 上传只接受 JPEG、PNG、WebP，单张最大 10 MB；服务端校验真实内容类型和大小，不能仅依赖文件扩展名。
- 产品主图固定一张，轮播图最多八张；详情图片仅引用本系统登记的图片。
- 面向客户展示的产品图片公开读取；写入/上传凭证申请必须经过后台鉴权。
- 对象存储 bucket 保持私有；上传先写入待确认对象，服务端校验后复制到新的已确认对象键，避免仍有效的上传凭证覆盖已登记图片。
- 客户端通过匿名媒体 API 读取已确认图片，而不是直接公开 bucket；Compose 中服务端使用 MinIO 内网地址，签名上传 URL 使用客户端可访问地址。
- 默认 bucket 在首次申请上传凭证时自动创建；不配置公开 bucket policy。

## 后果

- 业务服务不必中转所有图片字节，但必须校验上传授权、对象归属和确认流程。
- 业务服务在确认时读取并校验对象大小和实际图片内容；未确认对象和确认后的图片使用不同对象键。
- 产品响应和图文详情使用系统登记的图片资源，避免依赖未受控的外部图片地址。
- 本地和生产环境使用不同存储端点与凭据，但遵循同一接口约定。
- 图片删除、孤儿资源清理和缩略图处理策略尚未指定，不应擅自作为首期验收要求。
