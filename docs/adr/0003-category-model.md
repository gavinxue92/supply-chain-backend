# ADR-0003：分类层级与产品归属

- **状态**：已接受
- **日期**：2026-11-16

## 背景

小程序需要按食材分类浏览。运营需要维护分类顺序和上下架可见性，同时防止删除造成产品或子分类失去归属。

## 决策

- 分类最多两级：一级分类和二级分类。
- 每个产品只归属一个启用的末级分类。
- 一级和二级分类均可由运营设置排序。
- 同一父分类下分类名称唯一；不同父分类下允许同名。
- 停用一级分类时，小程序隐藏该分类、其全部子分类及产品，但不修改子分类或产品自身状态。
- 有关联产品或子分类时禁止删除分类；可通过停用表达暂不可用。

## 后果

- 产品不会同时出现在多个分类中；父分类浏览通过其二级分类包含的产品实现。
- 重新启用父分类可恢复原状态仍有效的子分类和产品可见性。
- 管理接口必须在服务端校验分类层级、名称唯一性和删除限制。
