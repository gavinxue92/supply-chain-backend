# 领域文档

本工作区采用单上下文布局。

## 探索代码前

- 阅读根目录 `CONTEXT.md`，了解项目目标、领域词汇与业务边界。
- 阅读根目录 `GLOSSARY.md`，统一项目专用术语。
- 阅读 `docs/domain-model.md`，了解已梳理的领域关系和聚合边界。
- 阅读 `docs/adr/` 中相关的架构决策记录。
- 如果这些文件不存在，直接继续，不必特别指出。只有在领域建模过程中明确了术语或决策后，才创建这些文件。

在问题、提案、假设和测试中统一使用 `CONTEXT.md` 或术语表中定义的词汇。如果缺少所需术语，不要自行创造同义词，应指出这一缺口。如果建议与现有架构决策记录冲突，必须明确说明。
