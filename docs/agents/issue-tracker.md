# 问题跟踪

本工作区使用 `.scratch/` 下的 Markdown 文件跟踪问题和规格说明。

## 约定

- 每个功能单独放在 `.scratch/<功能代号>/` 目录中。
- 规格说明保存为 `spec.md`。
- 每个实现任务单独保存在 `issues/` 目录中，文件名采用 `01-<任务代号>.md` 这样的格式。
- 在任务文件顶部附近注明当前状态；讨论内容追加到 `## 评论` 标题下。

发布工作项时，创建相应的文件和目录。获取任务时，读取用户提供的路径或任务引用。

使用 wayfinder 规划工作时，以 `map.md` 作为工作地图，并在 `issues/` 中为每个子任务创建单独的编号文件。子任务文件顶部附近应注明类型、状态和阻塞项；将已解决的问题记录在 `## 答案` 部分，并在地图中更新相应决策。
